# CI Investigation Task

你负责调查当前失败 job，只读取和验证当前仓库快照与当前 CI 证据。

## 强制规则

1. 允许搜索、读取文件和运行无副作用的诊断命令。
2. 禁止创建、修改、删除或格式化任何仓库文件。
3. 报告具体文件路径、行号、搜索结果和构建配置，不写空泛结论。
4. 不执行 git add、commit、push、reset 或 checkout。
5. 不查询 Revert 历史、不获取旧提交 diff、不寻找或复用以前的修复答案。
6. 不输出或记录密钥、Token、认证 URL 等敏感信息。
7. 流水线修复期间 `.git` 元数据会被外层系统临时隔离；这是正常安全措施，不是仓库缺失或阻塞证据。

调查完成后只报告当前证据和仍需验证的假设。调查本身不是修复。
